# 음성·문자 번역 알림장&칠판 사용 안내서

공유 사이트: https://voice-text-board.vercel.app

## 1. 이 프로그램은 무엇인가요?

`음성·문자 번역 알림장&칠판`은 선생님이 알림장 문구나 수업 안내를 큰 글씨로 보여 주고, 필요한 경우 여러 언어로 번역해 읽어 줄 수 있는 교실용 웹앱입니다.

한국어가 익숙하지 않은 학생도 선생님의 안내를 눈으로 보고, 번역문으로 확인하고, 음성으로 들을 수 있도록 돕습니다.

## 2. 1분 시작 안내

1. 사이트에 접속합니다.
   - https://voice-text-board.vercel.app

2. 알림장 또는 일반 칠판 모드를 선택합니다.
   - `알림장`: 날짜별 알림장 작성
   - `일반 칠판`: 수업 중 자유 안내

3. 본문에 안내할 내용을 입력합니다.
   - 직접 키보드로 입력하거나 `음성 입력`을 사용할 수 있습니다.

4. 필요한 언어를 선택합니다.
   - `언어 선택(한국어)` 버튼을 눌러 영어, 중국어, 베트남어 등 원하는 언어를 고릅니다.

5. `전체 읽기`를 누릅니다.
   - 한국어 또는 선택한 외국어 번역문을 음성으로 읽어 줍니다.

## 3. Gemini API 키 안내

AI 문장 다듬기와 정확한 다국어 번역을 사용하려면 각 사용자가 자신의 Gemini API 키를 직접 입력해야 합니다.

중요:

- 제작자의 API 키는 이 사이트에 포함되어 있지 않습니다.
- Vercel 서버에도 제작자 API 키가 저장되어 있지 않습니다.
- 각 선생님이 자기 Google AI Studio API 키를 입력해야 AI 기능을 사용할 수 있습니다.
- API 사용량과 비용은 각 사용자의 Google 계정 또는 프로젝트 정책을 따릅니다.

API 키 입력 방법:

1. 화면 오른쪽 위의 `API 연결 필요` 또는 `API 테스트 필요` 버튼을 누릅니다.
2. `Google AI Studio 열기`를 눌러 API 키를 만듭니다.
3. 생성한 키를 복사해 `Gemini API 키` 칸에 붙여넣습니다.
4. `Gemini API 사용`을 체크합니다.
5. `API 키 테스트`를 누릅니다.
6. `테스트 성공`이 나오면 AI 정리와 번역 기능을 사용할 수 있습니다.

공용 PC 주의:

- 공용 PC에서는 `개인 PC라면 이 기기에 API 키 기억하기`를 끄고 사용하세요.
- 사용 후에는 API 키 칸을 비우거나 브라우저 저장 데이터를 삭제하는 것이 좋습니다.
- 학생 이름, 상담 내용, 보호자 연락처 등 민감한 개인정보는 AI 정리와 번역에 넣지 않는 것을 권장합니다.

## 4. 알림장 모드

알림장 모드는 날짜별로 내용을 작성하고 저장하는 화면입니다.

주요 기능:

- 날짜별 알림장 작성
- `이전`, `오늘`, `다음` 버튼으로 날짜 이동
- 달력 버튼으로 날짜 선택
- 날짜별 자동 저장
- `기록 보기`로 이번 달 알림장 다시 열기
- `내보내기`로 엑셀 또는 PDF 저장용 파일 만들기

주말, 공휴일, 대체공휴일은 날짜 옆에 함께 표시됩니다.

## 5. 오늘의 자동 문구

알림장 모드에서는 날짜와 학교생활 상황에 맞는 기본 문구를 불러올 수 있습니다.

준비된 문구:

- 계기교육·안전 문구: 약 300개
- 학교생활 실천 문구: 약 300개
- 날짜별 계기교육 문구: 약 260일 분량

1번 문구는 계기교육, 교통안전, 실내 안전, 복도·계단 안전, 놀이·체육 안전, 도구 사용 안전, 건강·위생 안전, 재난 안전, 학교폭력 예방, 디지털·사이버 안전 등을 중심으로 합니다.

2번 문구는 듣기와 말하기, 협력과 배려, 감정 조절, 학습 습관, 책임과 정리, 갈등 해결, 존중과 다양성, 학교 공동체, 생활 예절, 자기 이해와 성장, 안전한 관계, 가정 연계 등을 중심으로 합니다.

체크를 켜면 해당 문구가 알림장에 들어가고, 체크를 끄면 자동 문구가 빠집니다. 1번 문구를 빼면 2번 문구가 자동으로 1번이 되도록 정리됩니다.

## 6. 일반 칠판 모드

일반 칠판 모드는 날짜별 알림장과 별도로 자유롭게 안내문을 띄우는 화면입니다.

활용 예:

- 수업 활동 순서 안내
- 준비물 안내
- 발표 주제 제시
- 모둠 활동 지시
- 급하게 전달해야 하는 교실 안내

## 7. 음성 입력

`음성 입력`을 누르면 선생님이 말한 내용을 텍스트로 변환합니다.

흐름:

1. 선생님이 말합니다.
2. `녹음 종료`를 누릅니다.
3. 컴퓨터가 들은 원문이 표시됩니다.
4. AI 또는 기본 규칙으로 다듬은 문장이 표시됩니다.
5. 선생님이 직접 수정 및 추가합니다.
6. `본문에 넣기`를 눌러 알림장 또는 칠판에 반영합니다.

외국어가 선택된 상태에서 음성 입력 내용을 본문에 넣으면, 번역도 다시 실행됩니다.

## 8. AI 문장 다듬기

Gemini API가 연결되어 있으면 음성 인식 결과나 본문을 더 자연스러운 교실 안내문으로 다듬을 수 있습니다.

AI 다듬기의 원칙:

- 원문 의미를 최대한 유지합니다.
- 선생님이 말한 핵심 내용을 함부로 줄이지 않습니다.
- 명백한 말더듬, 반복, 시작 안내, 음성 인식 잡음만 정리합니다.
- 최종 사용 전 선생님이 직접 확인하고 수정할 수 있습니다.

## 9. 다국어 번역

지원 언어:

- 한국어
- 영어
- 중국어
- 베트남어
- 필리핀어
- 우즈베크어
- 러시아어
- 캄보디아어
- 몽골어
- 태국어
- 네팔어
- 인도네시아어
- 미얀마어
- 일본어

번역은 원문 번호와 순서를 유지하도록 설계되어 있습니다. 번역 중에는 화면 가운데에 `지금 번역 중입니다. 조금만 기다려 주세요.`와 같은 안내가 표시됩니다.

번역 정확도 안내:

- Gemini API를 연결하면 브라우저 기본 번역보다 더 자연스러운 번역을 기대할 수 있습니다.
- 다만 모든 자동 번역은 100% 완벽하지 않을 수 있습니다.
- 중요한 안내, 안전 관련 문구, 보호자에게 공유할 문구는 선생님이 한 번 확인하는 것이 좋습니다.

## 10. 음성 읽기와 반복 안내

`전체 읽기`를 누르면 화면의 내용을 음성으로 읽어 줍니다.

조절할 수 있는 항목:

- 읽기 속도
- 남자/여자 목소리
- 반복 횟수
- 음량
- 읽을 언어

반복 읽기는 선생님이 같은 말을 여러 번 반복해야 하는 상황에 유용합니다.

활용 예:

- 활동 방법을 여러 번 안내할 때
- 준비물을 반복해서 알려야 할 때
- 학생들이 조용히 집중해야 할 안내를 일정한 목소리로 들려주고 싶을 때
- 한국어가 서툰 학생에게 번역된 문장을 반복해서 들려주고 싶을 때

외국어 번역문을 읽을 때는 현재 읽고 있는 번역 문장이 화면에 표시됩니다.

## 11. 화면 조정

수업 환경에 맞게 화면을 조정할 수 있습니다.

- 글자 크기 조절
- 자동 맞춤
- 글자색 변경
- 굵게
- 밑줄
- 줄 간격 조절
- 칠판 테마 변경

대형 TV나 전자칠판에서는 `자동 맞춤`을 켜면 문구가 화면 안에 보기 좋게 들어오도록 조정됩니다.

## 12. 저장과 내보내기

알림장 내용은 날짜별로 브라우저에 자동 저장됩니다.

`기록 보기`:

- 이번 달에 저장된 알림장을 다시 열 수 있습니다.

`내보내기`:

- 선택한 날짜 또는 기간의 알림장을 엑셀 파일로 저장할 수 있습니다.
- PDF 저장용 인쇄 화면을 열 수 있습니다.

## 13. 전체 삭제

`전체 삭제`를 누르면 현재 화면의 본문과 번역 결과가 함께 삭제됩니다.

주의:

- 현재 날짜와 현재 모드의 내용만 삭제됩니다.
- 다른 날짜의 알림장이나 다른 모드의 내용은 유지됩니다.
