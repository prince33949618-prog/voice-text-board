# 음성·문자 번역 알림장&칠판 PRD

## 1. 제품 개요

`음성·문자 번역 알림장&칠판`은 초등학교 교사가 알림장 문구와 수업 안내를 큰 화면에 보여 주고, 필요한 경우 여러 언어로 번역해 음성으로 들려줄 수 있는 교실용 웹앱이다.

교사는 한국어로 직접 입력하거나 음성으로 말한 내용을 학생용 안내문으로 다듬어 칠판처럼 표시할 수 있다. 다문화 학생이 있는 교실에서는 같은 내용을 영어, 중국어, 베트남어 등으로 번역해 즉시 보여 주고 읽어 줄 수 있다.

## 2. 대상 사용자

- 초등학교 담임교사
- 다문화 학생이 함께 생활하는 학급의 교사
- 대형 교실 디스플레이나 전자칠판을 사용하는 교사
- 반복 안내, 알림장 작성, 수업 지시를 더 빠르고 명확하게 전달하고 싶은 교사

## 3. 핵심 문제

교사는 수업 중 같은 안내를 여러 번 반복해야 하고, 한국어가 익숙하지 않은 학생에게는 같은 내용을 다시 풀어 설명해야 한다. 알림장 문구도 날짜별로 매일 작성해야 하며, 안전·생활지도·계기교육 문구를 자연스럽게 구성하는 데 시간이 든다.

이 앱은 교사의 말과 글을 큰 화면, 번역문, 음성 읽기로 연결해 반복 안내 부담을 줄이고 학생 이해를 돕는 것을 목표로 한다.

## 4. 제품 목표

- 교사가 말하거나 입력한 안내를 즉시 큰 글씨로 표시한다.
- 알림장과 일반 칠판을 구분해 사용할 수 있게 한다.
- 날짜별 알림장 내용을 자동 저장하고 다시 불러올 수 있게 한다.
- 기본 문구를 통해 계기교육·안전·학교생활 실천 문구 작성을 돕는다.
- 사용자가 직접 입력한 Gemini API 키로 AI 문장 다듬기와 다국어 번역을 사용할 수 있게 한다.
- 번역문을 선택한 언어의 음성으로 읽어 주고, 반복 읽기를 지원한다.
- 배포된 웹앱은 같은 주소로 공유하고, 개발자가 GitHub에 교정·개선 사항을 올리면 최신 버전이 자동 배포되도록 한다.

## 5. 핵심 기능

### 5.1 알림장 모드

- 날짜별 알림장 작성
- 이전 날짜, 오늘, 다음 날짜 이동
- 달력으로 날짜 선택
- 날짜별 자동 저장
- 이번 달 기록 보기
- 엑셀 또는 PDF 저장용 내보내기
- 주말, 공휴일, 대체공휴일 등 날짜 정보 표시

### 5.2 일반 칠판 모드

- 수업 중 자유 입력용 칠판
- 큰 글씨 표시
- 글자 크기, 글자색, 굵게, 밑줄, 줄 간격 조절
- 수업 안내, 발표 주제, 활동 지시 등 즉시 표시

### 5.3 오늘의 자동 문구

알림장 모드에서는 날짜와 학교생활 상황에 맞는 기본 문구를 불러올 수 있다.

- 계기교육·안전 문구: 약 300개
- 학교생활 실천 문구: 약 300개
- 날짜별 계기교육 문구: 약 260일 분량

1번 문구는 계기교육, 교통안전, 실내 안전, 복도·계단 안전, 놀이·체육 안전, 도구 사용 안전, 건강·위생 안전, 재난 안전, 학교폭력 예방, 디지털·사이버 안전 등을 중심으로 한다.

2번 문구는 듣기와 말하기, 협력과 배려, 감정 조절, 학습 습관, 책임과 정리, 갈등 해결, 존중과 다양성, 학교 공동체, 생활 예절, 자기 이해와 성장, 안전한 관계, 가정 연계 등을 중심으로 한다.

체크를 켜면 해당 문구가 알림장에 들어가고, 체크를 끄면 자동 문구가 빠진다. 1번 문구를 빼면 2번 문구가 자동으로 1번이 되도록 정리한다.

### 5.4 음성 입력

- 교사가 말한 내용을 브라우저 음성 인식으로 텍스트 변환
- 1단계: 컴퓨터가 들은 원문 확인
- 2단계: 말한 내용을 살려 다듬은 문장 확인
- 교사가 다듬은 문장을 직접 수정 및 추가 가능
- 본문에 넣으면 현재 알림장 또는 칠판에 반영
- 외국어가 선택된 상태라면 본문 반영 후 번역을 다시 실행

### 5.5 AI 문장 다듬기

사용자가 Gemini API 키를 직접 입력하고 테스트가 성공하면 다음 기능을 사용할 수 있다.

- 음성 인식 결과를 교실 안내문으로 정리
- 본문 문구를 학생이 읽기 좋은 문장으로 다듬기
- 원문 의미를 최대한 보존하고, 명백한 말더듬·반복·음성 인식 잡음만 제거

AI 결과는 최종 답이 아니라 교사용 초안이다. 교사는 사용 전 직접 확인하고 수정할 수 있어야 한다.

### 5.6 다국어 번역

지원 언어:

- 한국어
- 영어
- 중국어
- 베트남어
- 필리핀어
- 우즈베크어
- 러시아어
- 캄보디아어
- 몽골어
- 태국어
- 네팔어
- 인도네시아어
- 미얀마어
- 일본어

번역은 원문 항목 수, 번호, 순서를 유지해야 한다. 원문의 장소, 대상, 시간, 행동, 이유를 빠뜨리지 않고 목표 언어의 자연스러운 어순과 표현으로 옮긴다. 번역 결과에 다른 언어, 설명문, 마크다운이 섞이면 재번역 또는 교정 번역을 시도한다.

### 5.7 음성 읽기와 반복 안내

- 한국어 본문 읽기
- 선택한 외국어 번역문 읽기
- 읽기 속도 조절
- 음량 조절
- 반복 횟수 설정
- 남자/여자 목소리 선택
- 현재 읽는 문장 강조 표시

교사가 반복해서 말해야 하는 활동 안내, 준비물 안내, 과제 안내, 안전 안내를 텍스트나 음성으로 입력한 뒤 반복 읽기 기능으로 계속 들려줄 수 있다.

## 6. API 정책

이 앱은 배포 시 개발자 또는 제작자의 Gemini API 키를 포함하지 않는다.

원칙:

- 앱 코드에 API 키를 하드코딩하지 않는다.
- 배포 환경변수에 제작자 개인 API 키를 등록하지 않는다.
- 서버가 환경변수 API 키를 대신 사용하는 fallback을 두지 않는다.
- 각 사용자는 자신의 Google AI Studio Gemini API 키를 직접 입력해 사용한다.
- 입력한 API 키는 사용자의 브라우저 저장소에만 저장하거나, 공용 PC 모드에서는 현재 세션에서만 사용한다.
- API 사용량과 비용은 각 사용자의 Google 계정 또는 프로젝트 정책에 따른다.

민감한 학생 개인정보, 상담 내용, 보호자 연락처 등은 AI 정리와 번역에 넣지 않는 것을 권장한다.

## 7. 저장 정책

- 알림장과 일반 칠판 내용은 기본적으로 브라우저 로컬 저장소에 저장한다.
- 날짜별 알림장 데이터는 사용자 기기 안에 저장된다.
- 웹앱을 공유하더라도 다른 사용자의 알림장 내용이나 API 키가 서로 공유되지 않아야 한다.
- 배포 서버는 사용자 알림장 본문과 API 키를 장기 저장하지 않는다.

## 8. 배포 정책

권장 배포 구조:

- GitHub 저장소에 소스 코드 관리
- Vercel 또는 Netlify로 정적 웹앱 배포
- 빌드 명령: `npm run build`
- 출력 폴더: `dist`

개발자가 GitHub에 수정 사항을 올리면 배포 서비스가 자동으로 새 버전을 빌드하고 배포한다. 사용자는 같은 웹 주소로 접속하며, 새로고침 후 최신 버전을 사용할 수 있다.

## 9. 보안 및 개인정보 원칙

- 제작자 API 키를 저장소, 빌드 결과물, 배포 환경에 포함하지 않는다.
- `.env`, 로컬 설정, 로그 파일, 임시 파일은 배포 저장소에 올리지 않는다.
- API 키 입력칸은 기본적으로 숨김 처리한다.
- 공용 PC에서는 API 키 기억하기를 끄도록 안내한다.
- 학생 개인정보는 AI 처리 대상에서 제외하도록 안내한다.
