# 음성·문자 번역 알림장&칠판

초등학교 교사가 알림장 문구와 수업 안내를 큰 화면에 보여 주고, 필요한 경우 여러 언어로 번역해 음성으로 들려줄 수 있는 교실용 웹앱입니다.

## 주요 기능

- 알림장 모드와 일반 칠판 모드
- 날짜별 알림장 자동 저장
- 계기교육·안전 문구와 학교생활 실천 문구 자동 입력
- 음성 입력 후 문장 다듬기
- Gemini API를 이용한 AI 문장 정리와 다국어 번역
- 한국어, 영어, 중국어, 베트남어 등 다국어 표시
- 번역문 음성 읽기와 반복 읽기
- 글자 크기, 글자색, 줄 간격, 자동 맞춤
- 기록 보기와 파일 내보내기

## API 키 정책

이 저장소와 배포 앱에는 제작자의 Gemini API 키를 포함하지 않습니다.

- 사용자는 각자 자신의 Google AI Studio Gemini API 키를 입력해 사용합니다.
- API 키는 앱 코드, GitHub 저장소, Vercel 환경변수에 저장하지 않습니다.
- 개인 PC에서는 브라우저 저장소에 키를 기억할 수 있습니다.
- 공용 PC에서는 `이 기기에 API 키 기억하기`를 끄고 사용하는 것을 권장합니다.
- 학생 이름, 상담 내용, 보호자 연락처 등 민감한 개인정보는 AI 정리와 번역에 넣지 않는 것을 권장합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173/`을 엽니다.

## 빌드

```bash
npm run build
```

빌드 결과는 `dist` 폴더에 생성됩니다.

## Vercel 배포

Vercel에서 GitHub 저장소를 연결한 뒤 아래 설정으로 배포합니다.

- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`

Vercel 환경변수에 Gemini API 키를 넣지 않습니다. 이 앱은 사용자가 화면에서 직접 입력한 API 키만 사용합니다.
